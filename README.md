# ศูนย์รวมลิงก์สำหรับนิสิต (Student Link Hub)

เว็บรวมลิงก์ที่เป็นเว็บธรรมดา (HTML/CSS/JS ล้วน ไม่ต้องมีเซิร์ฟเวอร์ของตัวเอง)
เก็บโค้ดไว้บน GitHub แล้วให้ Supabase เป็นฐานข้อมูลและระบบล็อกอินผู้ดูแล

- **ผู้ใช้ทั่วไป** ไม่ต้องมีบัญชี ค้นหา กรองหมวด เก็บรายการโปรด และส่งคำขอเพิ่ม/แก้ไขเว็บได้
- **ผู้ดูแล** ล็อกอินด้วยอีเมลและรหัสผ่าน จัดการเว็บ หมวดหมู่ ลิงก์แนะนำ และอนุมัติคำขอได้ในหน้าเว็บ ไม่ต้องแตะโค้ด

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าเว็บ |
| `styles.css` | หน้าตา (สีหลักอยู่ที่ตัวแปรบนสุดของไฟล์) |
| `app.js` | การทำงานทั้งหมด |
| `config.js` | ใส่ค่าเชื่อมต่อ Supabase (แก้ไฟล์นี้ไฟล์เดียวตอนติดตั้ง) |
| `supabase/schema.sql` | สร้างตาราง กฎความปลอดภัย และหมวดหมู่เริ่มต้น |

## ติดตั้งครั้งแรก (ประมาณ 20 นาที ทำครั้งเดียว)

### 1) สร้างฐานข้อมูลที่ Supabase
1. สมัครที่ https://supabase.com แล้วกด **New project** ตั้งชื่อและรหัสผ่านฐานข้อมูล (เก็บรหัสไว้) เลือกภูมิภาคที่ใกล้ไทย เช่น Singapore
2. รอโปรเจกต์สร้างเสร็จ ไปที่เมนู **SQL Editor** > **New query**
3. เปิดไฟล์ `supabase/schema.sql` คัดลอกทั้งไฟล์มาวาง แล้วกด **Run** ต้องขึ้นว่า Success

### 2) สร้างบัญชีผู้ดูแล
1. เมนู **Authentication** > **Users** > **Add user** > **Create new user**
2. ใส่อีเมลและรหัสผ่านของผู้ดูแล ติ๊ก **Auto Confirm User** แล้วกดสร้าง
3. กลับไปที่ **SQL Editor** รันคำสั่งนี้ (เปลี่ยนอีเมลเป็นของผู้ดูแล) เพื่อให้บัญชีนี้เป็นแอดมิน
   ```sql
   insert into public.admins (user_id)
   select id from auth.users where email = 'admin@example.com';
   ```
4. เพิ่มผู้ดูแลคนอื่น: ทำซ้ำข้อ 1-3 ด้วยอีเมลของคนนั้น
5. ถอนสิทธิ์: `delete from public.admins where user_id = (select id from auth.users where email = 'admin@example.com');`

### 3) ปิดการสมัครสมาชิกเอง
เมนู **Authentication** > **Sign In / Providers** (หรือ **Providers**) > **Email** ปิด **Allow new users to sign up**
คนทั่วไปจะได้สร้างบัญชีเองไม่ได้ (แม้สร้างได้ ก็ไม่ใช่แอดมินอยู่ดี เพราะสิทธิ์อยู่ในตาราง `admins`)

### 4) ใส่ค่าเชื่อมต่อในเว็บ
1. เมนู **Project Settings** > **API** (หรือ **Data API / API Keys**)
2. คัดลอก **Project URL** และ **anon / public key**
3. เปิดไฟล์ `config.js` วางค่าแทน `YOUR-PROJECT` และ `YOUR-ANON-PUBLIC-KEY`
   (สองค่านี้ไม่ใช่ความลับ ห้ามใช้ `service_role` key เด็ดขาด)

### 5) นำเว็บขึ้นออนไลน์ (เลือกอย่างใดอย่างหนึ่ง)
- **GitHub Pages:** อัปโหลดไฟล์ทั้งหมดขึ้น repository > **Settings** > **Pages** > เลือก branch `main` และโฟลเดอร์ `/ (root)` > Save
- **Netlify / Cloudflare Pages:** ลากโฟลเดอร์โปรเจกต์ไปวาง หรือเชื่อมกับ repository ไม่ต้องตั้งค่า build

### 6) ตั้งค่าลิงก์ลืมรหัสผ่าน
เมนู **Authentication** > **URL Configuration**
- **Site URL**: ใส่ที่อยู่เว็บจริง เช่น `https://ชื่อคุณ.github.io/student-link-hub/`
- **Redirect URLs**: ใส่ที่อยู่เดียวกัน

เสร็จแล้ว เปิดเว็บ กดไอคอนโล่มุมขวาบน ล็อกอินด้วยอีเมลที่สร้างไว้

## การใช้งานประจำวัน (สำหรับผู้ดูแล ไม่ต้องรู้โค้ด)

- **เพิ่มเว็บ:** จัดการเว็บไซต์ > **+ เพิ่มเว็บไซต์** กรอกข้อมูล (ใส่โลโก้ได้ ไม่บังคับ) > บันทึก
- **ซ่อนเว็บชั่วคราว:** ในฟอร์มแก้ไข ปิดสวิตช์ "แสดงบนหน้าเว็บ" คนทั่วไปจะไม่เห็นและอ่านข้อมูลไม่ได้
- **อนุมัติคำขอ:** เมนู **คำขอจากผู้ใช้** มีตัวเลขแจ้งเมื่อมีคำขอใหม่ กด อนุมัติ หรือ ปฏิเสธ (พิมพ์ข้อความถึงผู้ส่งได้) ถ้าเป็นคำขอแก้ไข ค่าเดิมจะขีดฆ่าให้เห็นว่าเปลี่ยนอะไร
- **ลิงก์แนะนำ:** เปิดสวิตช์ของเว็บที่ต้องการให้ขึ้นหน้าแรก
- **หมวดหมู่:** เพิ่ม แก้ชื่อ ลบ และเลื่อนลำดับ ลบได้เฉพาะหมวดที่ไม่มีเว็บอยู่
- **เปลี่ยนชื่อเว็บและข้อมูลติดต่อ:** เมนู ตั้งค่า
- **ลืมรหัสผ่าน:** หน้าเข้าสู่ระบบมีปุ่ม "ลืมรหัสผ่าน" ระบบส่งลิงก์ตั้งรหัสใหม่ทางอีเมล

## ปรับแต่งหน้าตา (สำหรับคนที่รู้โค้ดหรือใช้ AI ช่วย)
- สีอยู่ที่ `:root { ... }` บนสุดของ `styles.css`
- ข้อความเริ่มต้นอยู่ที่ `DEFAULT_SETTINGS` บนสุดของ `app.js` (แต่ค่าจริงแก้ในหน้าแอดมิน > ตั้งค่า)

## ความปลอดภัย (สรุป)
- ทุกการอ่านและเขียนถูกควบคุมที่ฐานข้อมูลด้วยกฎ RLS ใน `schema.sql` ไม่ได้พึ่งการซ่อนปุ่มในหน้าเว็บ
- คนทั่วไปแก้ไขหรือลบเว็บไม่ได้ ส่งได้เฉพาะคำขอสถานะ "รออนุมัติ" และอ่านคำขอของคนอื่นหรือช่องทางติดต่อไม่ได้
- กันสแปมเบื้องต้น: ช่องดักบอท จำกัดคำขอรอตรวจต่อคนไม่เกิน 5 รายการ และทั้งระบบไม่เกิน 100 คำขอต่อชั่วโมง ถ้าถูกสแปมหนัก ค่อยเพิ่ม captcha (เช่น Cloudflare Turnstile)
- ข้อควรรู้: โปรเจกต์ Supabase แบบฟรีอาจถูกพักเมื่อไม่มีการใช้งานนานหลายวัน ถ้าเว็บโหลดข้อมูลไม่ขึ้น ให้เข้า Supabase dashboard แล้วกดกู้คืน (Restore) และตรวจเงื่อนไขล่าสุดของแพ็กเกจฟรีที่เว็บไซต์ Supabase
